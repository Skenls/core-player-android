# Core Player (Android)

Современный нативный клиент для медиасервера Core Player под Android, созданный на Kotlin и Jetpack Compose с продвинутой аудиосистемой на базе Jetpack Media3 (ExoPlayer).

---

## Возможности

- **Современный UI в тёмной теме**:
  - Глубокая тёмная палитра с поддержкой чистого AMOLED-режима.
  - Адаптивные градиенты и цветовые палитры для плавающего мини-плеера и карточек треков на основе обложек.
- **Плавающий мини-плеер (Floating Mini-Player)**:
  - Эргономичная капсула-пузырь над нижней панелью навигации и во вкладках альбомов.
  - Круговой индикатор прогресса вокруг кнопки воспроизведения.
  - Поддержка жестов: горизонтальные свайпы для перелистывания треков, свайп вверх для раскрытия полноэкранного плеера.
- **Полноэкранный плеер (Now Playing)**:
  - Размытый динамический фон под обложку текущего трека.
  - Синхронизированный караоке-текст песен (LRC) с плавным автоскроллом и фокусировкой на активной строке.
  - Управление очередью, случайный порядок (Shuffle) и режимы повтора (Repeat All / Repeat One).
- **Продвинутый аудиодвижок и кэширование**:
  - Jetpack Media3 (`MediaSessionService` + `ExoPlayer`) с фоновым сервисом воспроизведения.
  - Двухступенчатое упреждающее кэширование аудиопотоков: мгновенная перемотка без ожидания ответа сервера и предзагрузка следующего трека.
  - Поддержка настраиваемого кроссфейда (Crossfade) между треками без пауз и тишины.
  - Переключение аудиокодеков на лету (auto, mp3, flac, aac, opus) с корректной перемоткой.
  - Полнофункциональное управление воспроизведением в системной шторке уведомлений и на экране блокировки.
- **Медиатека и навигация**:
  - Адаптивный интерфейс для планшетов и широкоформатных экранов: 2 колонки на смартфонах и адаптивное масштабирование на широких экранах.
  - Экран «Главная»: недавние прослушанные треки, избранное, исполнители и плейлисты.
  - Экран «Обзор»: каталог альбомов, артистов и треков с подробными модальными страницами.
  - Просмотр дискографии конкретного исполнителя при клике на артиста.
  - Быстрое добавление и удаление треков из избранного прямо в списках альбомов и всех треков (кнопка-сердечко).
  - Полный каталог треков во вкладке «Все треки» со сбором всех песен по альбомам без случайных пропусков.
  - Управление плейлистами: создание, редактирование, удаление и добавление треков.
  - Поиск с историей поисковых запросов.
  - Экран ожидания подключения с доступом к настройкам сервера.

## Технологический стек

- **Язык**: Kotlin 2.0
- **UI**: Jetpack Compose (Material 3, Animations, Navigation Compose)
- **Аудио**: AndroidX Media3 (ExoPlayer, MediaSession, Session Service, OkHttp DataSource)
- **Сеть и данные**: Retrofit 2, OkHttp 3 (с персистентным CookieJar), Moshi
- **Загрузка изображений**: Coil 2 (Compose)
- **Архитектура**: MVVM, Kotlin Coroutines, StateFlow / SharedFlow

## Сборка и запуск

### Требования
- Android Studio Ladybug / Koala или CLI
- JDK 17
- Android SDK 35 (минимальная версия: Android 8.0, API 26)

### Команды

```bash
# Клонирование репозитория
git clone https://github.com/Skenls/core-player-android.git
cd core-player-android

# Запуск модульных тестов
./gradlew testDebugUnitTest

# Сборка Debug APK
./gradlew assembleDebug

# Установка на подключенное устройство через ADB
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
